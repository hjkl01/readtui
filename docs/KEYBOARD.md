# Keyboard Interaction

## Library

| Key | Action |
|---|---|
| `j` / `k`, arrows | Move selection |
| `Enter` | Open selected book |
| `a` | Open a path to import/open |
| `?` | Help |
| `q` | Quit |

## Reader

| Key | Action |
|---|---|
| `j` / `k`, arrows | Scroll |
| `Space` / `PageDown` | Forward page |
| `PageUp` | Backward page |
| `g` / `G` | Start / end |
| `n` / `N` | Next / previous chapter |
| `t` | Table of contents |
| `/` | Search |
| `b` | Add bookmark |
| `Esc` / `q` | Return to library |

Future versions will provide a key-binding editor and conflict detection. All primary actions must remain usable without a mouse.
